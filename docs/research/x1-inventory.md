## (e) The turn shapes that exist today

**The shape string.** `SandboxCanaryKey.shape` is `CanaryShape.key(settings, launch:)` (`Orchestrator+Ultra.swift:22-33`):

```swift
public static func key(_ settings: ClaudeSettings, launch: String?) -> String {
    guard let launch else { return settings.shape() }
    return StableHash.fnv1a64(settings.shape() + "|" + launch)
}
/// `task`, `ultra-small` or `ultra` for a decision that fans out; nil otherwise.
public static func launch(_ d: ModeDecision?) -> String? {
    guard let d else { return nil }
    if let w = d.workflow { return w.variant == .small ? "ultra-small" : "ultra" }
    return d.subagents != .off ? "task" : nil
}
```

and `ClaudeSettings.shape()` (`Sandbox/ClaudeSettings.swift:114`) is `StableHash.fnv1a64` of the compiled settings JSON (sorted keys) with **every string replaced by `"s"` and every array cut to its first element** — so paths, domains, counts and ids never change a shape; a key appearing or disappearing, a boolean or number changing, or an array going empty ↔ non-empty does. Placeholders that are never a turn's shape: `SandboxCanary.anyShape = ""` and `"doctor"` (`SandboxCanary.swift:238-239`). The key is `(fingerprint = CanaryProbes.keyFingerprint(cli: CLIFingerprint.key, probes: digest), shape, osVersion)`.

**Callers that build shapes:** `Orchestrator.performTurn` (`Orchestrator.swift:1291-1303, 1317-1318, 1404-1406`: `CanaryShape.key(TurnProfileCompiler.profile(for: turnRequest(mcpConfigPath: "/dev/null")).settings, launch: CanaryShape.launch(mode))` — the gate, the re-gate after a lost grant, and the backstop on the compiled request); `Orchestrator+Ultra.fanOutVerified` (:191-192, the fan-out shapes' own keys); `Orchestrator+Canary.requireSandboxVerified` (:76); `ExtensionTry` (`Extensions/ExtensionTry.swift:281`, `compiled.settings.shape()` for `brahma ext try`); `SandboxCanary.verifiedKey` (`SandboxCanary.swift:505-508`, `settings.shape()` of the canary's own compiled turn) and `shapeProblem` (:513); `brahma canary run` (`CanaryCommands.swift:60-69`) enumerating `SandboxCanary.TurnSpec.shapeKey(spec)` = `"\(allowedDomains.isEmpty)|\(webDomains.isEmpty)|\(allowLocalBinding)|\(plan)"` (:291-293) — the CLI's own statement of which company settings move the standard work turn's shape. `ModeCanary.shapes()` (`Engine/ModeCanary.swift:18`) enumerates the three effort shapes `quick`/`standard`/`deep` (no sandbox). `ProbeShape` (`Modes/ProbeGates.swift:6`) names the probe-gate shapes `sandboxed-task`, `ultra`, `sandboxed-plan`.

**The dimensions that change the compiled settings (and therefore the shape), from `ClaudeSettingsCompiler.compile` and `TurnProfileCompiler.profile(for:)`:**

| Dimension | Values | Effect on the settings JSON |
|---|---|---|
| profile | `sandboxed`, `workspace`, `full` | sandboxed: the `sandbox` block (`enabled`, `filesystem.denyRead/allowWrite…`, `network.allowedDomains/allowLocalBinding/allowAllUnixSockets/allowMachLookup`), `permissions.allow = ["Bash", "mcp__company", WebFetch(domain:…)…]`, the Bash denies; workspace: `permissions.deny` for `deniedPaths` (read/edit rules); full: neither. |
| kind | `work`, `review`, `audit`, `notice`, `plan`, `show` (`Model/Turn.swift:7`) | plan: `plansDirectory` key, `permission-mode plan`, `BuiltinTools.plan`; review/audit: `BuiltinTools.review`, sub-agent tools banned (`restricted`); notice/show/work share the work shape (tools differ only by argv). |
| mode (`ModeDecision`) | `quick`, `standard`, `deep`, `plan`, `ultra` (`WorkMode`) with an effort cap | `maxEffortLevel` (one shape per emitted cap), `availableModels`, `fastMode: false`, `disableWorkflows`/`enableWorkflows` + `workflowSizeGuideline`/`workflowKeywordTriggerEnabled` (Ultra only), the pre-tool hook block (present only with a `hookExecutable`). |
| sub-agents / fan-out (`launch`) | `nil`, `task`, `ultra-small`, `ultra` | the settings are byte-identical for a Task turn (its tools travel in argv), and Ultra-small equals Ultra up to strings, so the launch string is **appended to the key** rather than read from the settings. |
| network (sandboxed) | `allowedDomains` empty / non-empty, `webDomains` empty / non-empty, `allowLocalBinding` true / false | arrays → first element, so only emptiness and the boolean count (`TurnSpec.shapeKey`). |
| mounts (extension parts) | none / some | `enabledPlugins` (bundled plugins off), `disableBundledSkills`, the `Skill(...)` denies replacing `--disable-slash-commands`. |
| hooks | pre-tool (`hookExecutable` set), post-tool (`TaintPolicy.postToolHook`) | `hooks.PreToolUse` / `hooks.PostToolUse` blocks. |
| mach marker | present on sandboxed turns | `sandbox.network.allowMachLookup` array. |
| itemless vs item | `SandboxScope.Shape { item(key), itemless, review(String?), audit, plan(key) }` (`Sandbox/SandboxScope.swift:639`) | changes the cwd and the write paths — **strings**, so it does **not** change `ClaudeSettings.shape()` unless an array becomes empty (for example an itemless turn with no worktree write path). Task 1's goldens must include one item and one itemless work turn to confirm the pair hashes equal (or not). |
| concierge (`TurnRequest.concierge`) | the owner's show-request run | its own profile (`conciergeProfile`), Workspace-like, never canary-gated. |

**The exact set of shape strings today cannot be listed as literals:** they are fnv1a64 hashes computed at launch from the compiled settings, and the sandboxed ones depend on each company's network flags and on whether extension parts mount. What *is* fixed is the generating set above; the canary gate applies only to `profile == .sandboxed`. For T2's `TurnShape`, Ruling 10 therefore means: `TurnShape` must carry `profile`, `kind`, `mode` (with its effort cap), `launch` (`nil`/`task`/`ultra-small`/`ultra`), the three network flags, `mounts.isEmpty`, the two hook presences and the mach-marker presence, and `TurnShape.key` must be computed **by compiling the settings and calling `CanaryShape.key`**, never by concatenating the fields — that is the only way the identity "T2's key == today's canary string for every shape" can hold. Task 1 records one golden (argv, settings JSON, `shape()`) per cell of: profile {sandboxed, workspace, full} × kind {work, review, audit, notice, plan, show} × mode {quick, standard, deep, plan, ultra} × launch {nil, task, ultra-small, ultra} × network {default, domains, local-binding} × {item, itemless} — pruned to the combinations the compiler can produce (Ultra and `task` only sandboxed work; plan kind only plan mode; review/audit never fan out) — plus the concierge profile.
