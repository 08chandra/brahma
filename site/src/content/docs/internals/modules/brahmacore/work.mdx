## Purpose

The work system's rules, as pure code. `WorkPolicy` says which actor may change which item fields. `AutonomyPolicy` and `AutonomyPreset` say how much the owner wants to be asked; `ReservedMatters` are the categories no preset ever approves. `TierBudget` caps an item's turns, counted tokens and cost by effort tier. `ModePolicy.select` decides each turn's mode, model and effort with one reason string per step. `ReviewDigest` is what a reviewer sees: spec, check result and the real diff, never the author's conversation. `Handoff`, `ProgressFile` and `NotesFile` are what agents leave each other. `MergeSafety`, `Liveness`, `WaitForGraph` and `Watchdog` catch collisions, stalls, deadlocks and loops.

## Key types

- [`WorkPolicy`](/api/brahmacore/documentation/brahmacore/workpolicy/) and [`WorkField`](/api/brahmacore/documentation/brahmacore/workfield/) — who may change what.
- [`AutonomyPreset`](/api/brahmacore/documentation/brahmacore/autonomypreset/) and [`ReservedMatters`](/api/brahmacore/documentation/brahmacore/reservedmatters/) — how much to ask, and what always asks.
- [`TierBudget`](/api/brahmacore/documentation/brahmacore/tierbudget/) — turns, tokens and cost per effort tier.
- [`ModePolicy`](/api/brahmacore/documentation/brahmacore/modepolicy/), [`ModeInputs`](/api/brahmacore/documentation/brahmacore/modeinputs/) and [`ModeDecision`](/api/brahmacore/documentation/brahmacore/modedecision/) — the work-mode decision.
- [`ReviewDigest`](/api/brahmacore/documentation/brahmacore/reviewdigest/) — what a reviewer is shown.
- [`Watchdog`](/api/brahmacore/documentation/brahmacore/watchdog/) and [`Liveness`](/api/brahmacore/documentation/brahmacore/liveness/) — loops and stalls.

## How it connects

- **Called by Orchestrator.** Each work turn's mode comes from `ModePolicy.select`; the budget step reads `TierBudget.of`; the liveness scan runs every `Liveness.scanInterval`; the turn-end step builds a `TurnObservation` for the watchdog; review turns render a `ReviewDigest`.
- **Called by Store.** Item changes pass `WorkPolicy`; asks check `ReservedMatters`; merges clear `MergeSafety` flags; the liveness pass finds cycles with `WaitForGraph`.
- **Called by Turns, MCP and Model.** A `ClaudeCommand` carries the `ModeDecision`; `CompanyTools` holds `ModeQuotas`; `Company` stores an `AutonomyPreset`.
- **Calls Modes, Engine, Git and Messaging.** `ModeInputs` carry an `UltraAdmission` and a `PlanTier`; the review digest lists `GitChange`s; the watchdog DMs through `MessageRouter`.
