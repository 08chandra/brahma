## Purpose

The SwiftUI views and the menu bar extra: the executable the owner runs. `BrahmaApp` declares the main window, the pop-out Agent Map window and the `MenuBarExtra`. `AppDelegate` boots: it picks the owner-key store and the secrets vault, opens the database the way the CLI's `openStore()` does, builds the `AppModel` and the `EngineHost`, and posts Inbox banners through `UNNotificationPoster`. `MainWindow` draws the top bar, company rail, sidebar and detail pane; the views under `Views/` each render one part of the snapshot. `BrahmaTheme` turns `ThemeHex` into SwiftUI colours and fonts. `Harness` runs the smoke, snapshot and map-bench launch modes.

## Key types

This target has no public symbols, so there is no API reference for it. The types below are internal.

- `BrahmaApp` — the `App`: the `main` window, the `map` window and the menu bar extra.
- `AppDelegate` — boot, the signal handlers, the quit path and the notification poster.
- `MainWindow` — the shell: top bar over rail, sidebar and detail, plus the sheets.
- `MenuBarContent` — a native menu: the emergency stop, totals, per-company toggles, open and quit.
- `AgentMapPanel` — the org-chart panel and its header, inline or in the pop-out window.
- `BrahmaTheme` — the design tokens every view uses instead of ad-hoc colours and fonts.

## How it connects

- **Calls BrahmaAppModel.** `61` of the `65` files import it. `AppDelegate` builds the `AppModel` and the `EngineHost`; `MenuBarContent` renders `model.menuBar`; `UNNotificationPoster` implements `NotificationPosting`; every colour in `BrahmaTheme` reads `ThemeHex`.
- **Calls BrahmaKeychain.** Only `AppDelegate` imports it: `PlatformOwnerKeyStore.resolve` for the owner key, and `PlatformSecretVault.resolve` twice, non-interactive for the engine and interactive for the owner's "Load secrets".
- **Calls BrahmaMapKit.** `AgentMapPanel` mounts an `OrgView`; `Harness` finds the `MapSKView` for `--map-bench`.
- **Calls BrahmaCore directly** for the model types the views show, for example `EmergencyStop.buttonTitle` in the menu and `BrahmaPaths.fromEnvironment()` at boot.
- **Called by nothing.** It is an executable target; `Package.swift` lists its dependencies as `BrahmaAppModel`, `BrahmaKeychain` and `BrahmaMapKit`.
